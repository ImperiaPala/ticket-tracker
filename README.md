# Трекер заявок
Тестовый трекер заявок, создан чтобы проверить свои знания и научиться чему-то новому.
## Как запустить
- Python 3+
- `python main.py`

## Что умеет
- Создать заявку (Заголовок, описание, приоритет)
- Показать все заявки
- Сменить статус заявки по номеру (новая -> в работе -> закрыта)
- Удалить заявку по номеру
- Данные сохраняются в json, в log пишутся действия

## Структура
- main.py - меню и запуск
- ticket.py - класс заявки, заявка с проверкой приоритета и сменой статуса
- storage.py - хранилище, сохранение и загрузка json, добавление, удаление, сортировка и фильтры
- helpers.py - лог и приоритет
